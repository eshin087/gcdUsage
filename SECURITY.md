# Security

This is a personal preview application. Keep your operating system and installed coding tools updated, and install builds only from the intended repository.

History previews, exports, and synchronized records may contain private text. Share them only with trusted people. Shared-folder synchronization does not authenticate individual writers. A compromised operating-system account or trusted shared folder is outside the app's protection boundary.

The September 2026 review covered desktop permissions, untrusted record handling, exports, executable discovery, dependencies, and repository descriptions. Security review and passing tests do not guarantee the absence of vulnerabilities. Some upstream Unicode dependencies have maintenance advisories with no published replacement versions in the current dependency chain.

Please report a suspected issue privately to the repository owner. Do not post private history or sign-in information in an issue or build log.

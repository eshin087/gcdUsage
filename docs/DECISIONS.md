# Product decisions
Current user instructions can revise these choices. Historical context is in HISTORY_LESSONS.md; executed evidence is in VALIDATION.md.

| Decision | Current direction | Basis |
| --- | --- | --- |
| Visual language | Site terminal, cream/charcoal, regular JetBrains Mono, restrained accents | Approved September design |
| Dock | D1 quiet dividers, padded text, green values and spelled-out reset | Selected D1 |
| Reset color | Muted reddish labels and times on dashboard and Windows dock, with light-theme contrast | September 11 request |
| Overview | O1 readable allowance columns and grouped reconnect action | Selected O1 |
| Hover history | H2 one-line prompts, compact model column, automatic older paging | Explicit selections |
| Duration dialog | T2 native themed presets and custom whole units | Explicit T2 |
| Dock controls | Resize any unlocked corner; Hide and tray double-click/Show dock | September 11 request |
| Hidden state | Remain hidden after restarts until explicitly restored | Explicit answer |
| Claude session | Renew through saved Claude Code credentials; respect logout/revocation | Persistence request |
| Insights | Local patterns and graphs plus allowance forecasting | Explicit forecast selection |
| Recent percentages | Show on the dock, dashboard allowance cards and Model advice | Explicit placement answer |
| Recent duration | Share the dock duration, including custom values | Explicit duration answer |
| Delivery and cost | Existing repo, suitable manual builds, zero GitHub spending | Explicit policy |

The extra dock usage row expands its logical height from 120 to 144 to preserve padding. This is an implementation detail supporting the requested additional information, not a new visual direction.

Budget alerts, project comparisons, session timelines and weekly digests were alternatives offered to the user; forecasting was selected. They are not an authorized implementation backlog.

Earlier build approval does not cover a later update under the current restriction. Check AGENTS.md and current conversation authorization.

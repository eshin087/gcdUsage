# GitHub: file hosting only

No GitHub spending is authorized. Actions is disabled for this repository and all build workflows are removed. Generated Actions artifacts and caches are cleared. Source files, documentation and existing release downloads are retained.

Do not create workflows, start hosted runners, use Codespaces, add billable integrations or request payment/spending-limit changes. Do not restore automation from older commits or branches. Tags and ordinary pushes must not trigger builds or deployments.

Builds and tests must run manually on a suitable existing computer. Native compilation on the current development host remains paused until its restart issue is resolved. Inspect manually built packages for private compiler paths before uploading them. An unavailable build environment is a blocker, not authorization to spend money.

These changes prevent this repository from starting Actions work. They do not erase any previous charges or control unrelated repositories or account subscriptions.
